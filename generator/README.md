# @nte.zip 카드뉴스 생성기

이환(NTE) 인스타 카드뉴스(1080×1350 PNG)를 만드는 코드와 재료. 어느 채팅에서든 이 폴더만 있으면 같은 디자인으로 다시 만들 수 있다.

## 실행

```bash
pip install pillow numpy
cd generator
python3 news_frost.py      # → out/frost/*.png
```

| 파일 | 내용 |
|---|---|
| `cardnews_v2.py` | 공통 틀(색·폰트·`brand_bar`·`fade`·`tracked`) + 엘림 신캐 요약 9장 |
| `news_tga.py` | TGA 2026 후보 소식 5장 |
| `news_15cal.py` | 1.5 일정 4장 |
| `news_frost.py` | 궤도 너머 「서리의 고리」 5장 — 새 소식 카드의 기본 틀로 쓰기 좋음 |

새 주제는 `news_frost.py`를 복사해 슬라이드 함수만 바꾼다. 공통 함수는 `import cardnews_v2 as c`로 가져온다(import해도 엘림 9장은 다시 그리지 않음).

## 재료

- `fonts/` Pretendard(본문), Inter Display(숫자) — 둘 다 OFL 라이선스
- `assets/characters/` 공식 일러스트·SD, `*_x2.png`는 2배 업스케일본, `cards/`는 캐릭터 카드 이미지
- `assets/info_cards/` 공식 「정보 공개」 카드 원본 — 마무리 장 라인업 타일로 사진 칸만 잘라 씀
- `assets/icons/` 인게임 아이콘(속성 `element/*_icon.png`, 재료, 각성, 아크 등)

## 디자인 규칙

- 배경 #EFF0F6 단색, 글자 #242942, 보조 #505A82·#6A80B4, 선 #C4C9DC, 패널 #D5D9E8, 강조 #5C54D6
- 그라데이션·글로우·알약 태그·이모지·범용 아이콘 금지. 아이콘은 인게임 것만
- 실제 공식 이미지를 넣되 글자를 덮지 않게
- 제목은 짧고 담백하게("이번 버프", "적 약점", "추천 파티"). "누구나 받는다", "잘 먹힌다" 같은 AI 말투 금지
- 수치·추천은 한·중 커뮤니티 주류 의견만, 출처끼리 다르면 뺀다
- 하단 출처 줄에 인벤·디시·나무위키 등 사이트 이름 금지
- 마무리 장: 팔로우·좋아요 요청 + 정보 공개 카드 라인업(출시 순서), 남는 칸은 "?"

## 올리기

카드를 만든 뒤 채팅에서 **"nte.zip에 올려"** — 이미지를 이 저장소 `cards/날짜_주제/`에 올리고, 확인을 받은 뒤 @nte.zip에 게시한다.
